# 🎓 Цифровой кампус: Личный кабинет и Справочник первокурсника
> Проектная деятельность · Московский Политех · 2026

Единый цифровой портал для первокурсников Московского Политеха:
- 🏠 **Личный кабинет студента** — карточка профиля, важные дедлайны и памятка первокурсника
- 📅 **Расписание занятий** — синхронизация по группам (интеграция с rasp.dmami.ru)
- 📖 **Интерактивный справочник** — проверенная база знаний по стипендиям, общежитиям, справкам и контактам служб
- 🤖 **Интеллектуальный ИИ-ассистент** — ответы на сложные вопросы строго по официальным регламентам вуза с цитированием первоисточников

## 🛠️ Для разработчиков: локальный запуск

> Разработчикам локальный запуск необходим для того, чтобы **проверять работу своего модуля перед отправкой кода в репозиторий** (чтобы не сломать работающий сайт).

### 1. Клонировать репозиторий:
```bash
git clone https://github.com/terpeterter/campus-assistant.git
cd campus-assistant
```

### 2. Создать и активировать виртуальное окружение:
**Windows (PowerShell):**
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости:
```bash
pip install -r requirements.txt
```

### 4. Запустить веб-интерфейс локально:
```bash
streamlit run app.py
```
После запуска в браузере откроется локальная версия (`http://localhost:8501`).

## 🌿 Правила работы с Git (Git-flow)
1. **Никаких прямых коммитов в `main`!** Ветка `main` защищена.
2. Для каждой задачи создавайте отдельную ветку от `main`:
   ```bash
   git pull origin main
   git checkout -b feature/название-фичи
   ```
3. Сделайте коммит и отправьте ветку на GitHub:
   ```bash
   git add .
   git commit -m "feat: понятное описание того, что сделали"
   git push -u origin feature/название-фичи
   ```
4. Откройте **Pull Request (PR)** в `main` на GitHub и запросите код-ревью у тимлида.
