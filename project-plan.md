# 🧭 ПолиГид (PolyGuide) — План разработки
> Проектная деятельность · Московский Политех · 2026

## Контекст проекта

**Задача из распоряжения:** создать концепт и рабочий прототип единого цифрового навигатора Московского Политеха, решающего задачи студентов, абитуриентов и родителей: расписание занятий, база знаний по регламентам, оплата обучения, навигация по кампусу и умные консультации.

**Что необходимо подготовить к защите (Definition of Done):**
1. Таблица JTBD и карта болей первокурсников
2. **Анализ ТРИЗ и Информационная безопасность:** [docs/triz-and-security.md](docs/triz-and-security.md)
3. **Интерактивный прототип / MVP** — рабочий портал: инфоцентр, расписание, база знаний и RAG-сценарий вопрос-ответ с источниками данных и цитированием
4. **Архитектура и техническая спецификация** — схема компонентов, RAG-контур, сервис расписания, API, безопасность
5. Отчёт об использовании ИИ-агентов при разработке
6. Итоговая презентация проекта (5–7 мин)

> [!NOTE]
> Пункты 1, 2, 5, 6 распределены между смежными ролями потока (исследователи, аналитики). Команда разработки (8 человек) отвечает за пункты 3 и 4 — создание рабочего прототипа (MVP) и его программной архитектуры.

## Технологический стек

Выбор стека сформирован на базе анализа требований проекта и ориентирован на надёжность, импортонезависимость и скорость создания MVP:

| Слой | Технология | Обоснование выбора |
|---|---|---|
| **Язык** | Python 3.12+ | Индустриальный стандарт для ML/NLP и интеграций |
| **Веб-интерфейс** | **Streamlit** | Быстрое создание интерактивных веб-приложений без отдельного фронтенда |
| **Поиск по документам** | **rank_bm25** (BM25) → опционально **ChromaDB** | BM25 обеспечивает высокую точность по ключевым словам без GPU. ChromaDB — опциональный векторный слой |
| **LLM API** | **GigaChat API** / **YandexGPT** (fallback: локальная модель) | Российские модели с бесплатным доступом для разработчиков и студентов, поддержка русского языка из коробки |
| **Парсинг документов** | **PyMuPDF** (PDF) + встроенные средства Python (txt, md) | Высокая производительность и точное извлечение текста с разбивкой по страницам |
| **Хранение данных** | Директория `data/` + файловый JSON-индекс | Прозрачное хранение регламентов кампуса с метаданными |
| **Конфигурация** | **python-dotenv** + `.env` | Безопасное хранение API-токенов вне системы контроля версий |
| **Контроль версий** | **GitHub** + Git-flow + защищённая ветка `main` | Командная разработка с обязательным код-ревью |

> [!NOTE]
> Для пилотной базы из 30–50 регламентов кампуса алгоритм BM25 обеспечивает достаточную точность без необходимости аренды GPU-серверов. Векторный поиск рассматривается как расширение архитектуры при масштабировании базы знаний.

## 👥 Распределение команды разработки (8 человек)

> [!IMPORTANT]
> Модульная архитектура обеспечивает параллельную работу: границы компонентов строго изолированы, каждый разработчик ведёт работу в feature-ветке и передает код в релиз через Pull Request.

| Роль / Модуль | Состав | Зона ответственности | Файлы модуля |
|---|:---:|---|---|
| **Тимлид (Архитектура и координация)** | 1 чел. | Архитектура системы, Git-flow, код-ревью, интеграция расписания (`rasp.dmami.ru`) и RAG | `core/schedule_service.py`, `core/rag_chain.py` |
| **Модуль 1: Загрузка и обработка документов** | 1 чел. | Парсинг PDF/MD/TXT, очистка текста, разбивка на смысловые фрагменты (чанки) | `core/document_loader.py` |
| **Модуль 2: Индексация и поиск (Retriever)** | 2 чел. (пара) | Алгоритм поиска BM25, сохранение/загрузка индекса, ранжирование top-K | `core/retriever.py`, `data/index/` |
| **Модуль 3: Интеграция с нейросетью (LLM)** | 1 чел. | Подключение API модели (GigaChat / YandexGPT), системные промпты, обработка ошибок | `core/llm_client.py` |
| **Модуль 4: Пользовательский интерфейс (UI)** | 2 чел. (пара) | Веб-портал на Streamlit: вкладки дашборда, карточки расписания, аккордеоны справочника, чат | `app.py`, `pages/admin.py` |
| **Модуль 5: Тестирование, база знаний и справочник** | 1 чел. | Набор тестовых сценариев (30–50 вопросов), наполнение базы знаний (FAQ) и контактов | `tests/`, `config/contacts.json`, `config/faq.json` |

## Сравнение провайдеров LLM

| Провайдер | Преимущества | Особенности |
|-----------|--------------|-------------|
| **GigaChat (Сбер)** | Бесплатный тариф для физлиц, качественная обработка русскоязычного контекста | Регистрация через Сбер ID |
| **YandexGPT** | Специальные программы для образовательных учреждений, высокая скорость работы | Требуется настройка каталога Yandex Cloud |
| **Локальная модель (Ollama)** | Полная автономность, отсутствие сетевых задержек | Требует вычислительных ресурсов (8+ ГБ RAM) |

> [!TIP]
> Базовым провайдером для MVP выбран **GigaChat**. Модульная архитектура в `core/llm_client.py` позволяет при необходимости переключить поставщика модели без модификации остальной части системы.
