# 📂 Изолированное хранилище официальных и бюрократических документов

В этой папке хранятся исходные официальные нормативно-правовые акты, приказы, регламенты и архивные материалы (например, `Распоряжение №598-Р`, `ДМ2026 (2) (1).pdf` и др.).

### Почему они изолированы:
1. Поисковый индекс и RAG-ассистент **ПолиГид** считывают материалы только из каталога `data/documents/`.
2. Бюрократические многостраничные распоряжения содержат юридический шум, который не предназначен для прямого поиска студентами без предварительной обработки и структурирования.
3. Документы из этой папки **не читаются** модулем `core.document_loader` и сохраняются в исследовательских и архивных целях.
